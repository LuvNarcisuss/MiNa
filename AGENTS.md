# MiNa project rules

Build an iPhone-only bedtime voice community named MiNa. Follow docs/MiNa-Product-Design.md. The central plus opens AI Companion. Use the supplied design exports and natural English. Keep the original boards and archives intact. The app uses bundled React and TypeScript pages in a local ZIP opened by a React Native iOS host. Keep service availability, profile ownership and payment states truthful. Use stable identifiers and durable writes for personal data. Release signing, service accounts and purchase identifiers require project-specific configuration.

Static inspection and project metadata generation are permitted. Compilation, type checking, launching and runtime tests require explicit user authorization. Keep UI sources in web/src, original-derived artwork in web/public/art and native integration in ios.
